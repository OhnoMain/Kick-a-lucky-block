# Kick a Lucky Block Script

Automate **Roblox Kick a Lucky Block** 

--- 

## ✨ Features

- **Auto Strength Farming**  
  Automatically trains strength without manual clicking.

- **Auto Kick**  
  Continuously kicks blocks and collects them

- **Auto Upgrade**  
  Automatically upgrades brainrots

- **Auto Rebirth Farm**  
  Rebirths automatically
